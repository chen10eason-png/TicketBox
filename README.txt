TicketBox v1.4 Stable Editor

更新重點
1. 新增/編輯票券改成固定式全螢幕編輯器，分成「基本資料 / 圖片QR / 其他」三頁，減少整頁上下滑動與 iOS 彈跳感。
2. 票券封面照片新增三種加入方式：拍照 / 相簿 / 檔案。
3. QR Code / 條碼圖片同樣提供：拍照 / 相簿 / 檔案。
4. 可直接移除已選的封面或票碼圖片。
5. 保留原有 TicketBox localStorage 資料 key 與升級機制，更新同一 GitHub Pages 網址時不會主動刪除舊票券。
6. App icon / PWA / 離線快取繼續保留。

GitHub Pages 更新：請把本資料夾內的 index.html、manifest.webmanifest、sw.js、icons 資料夾一起上傳/覆蓋到原本相同的 repository。
